# Kravspec (sammanfattat från examinationsbeskrivningen)

## Inlämning
Tre filer i en zip, samt samma filer i ett GitHub-repo med länk i README.
1. Jupyter Notebook (.ipynb) med markdown-celler som förklarar logiken
2. Datafil (.csv eller .json) med data programmet hämtat eller sparat
3. README (.md eller .pdf) med mål, metod, resultat, analys, reflektion, certifikat, GitHub-länk, installation

Minst 5 commits på GitHub, gärna fler och med tydliga meddelanden.

## Obligatoriska tekniska delar
- Variabler och datatyper: int, float, str, bool, listor, dict
- If-satser
- Minst en for eller while-loop
- Minst 3 till 5 egna funktioner med parametrar och returvärden
- Felhantering med try/except där det är rimligt, till exempel API-anrop och filhantering
- Datahantering: läsa eller spara i JSON eller CSV
- Minst en klass med attribut och metoder
- Minst en barnklass som ärver från en basklass
- Minst ett standardbibliotek, till exempel json, csv, datetime, os, statistics
- Minst ett externt bibliotek, till exempel requests eller matplotlib
- Hämta data från ett offentligt API eller läsa från extern fil

## README ska innehålla
Titel, mål, metod, resultat, analys kopplad till AI-branschen, reflektion, GitHub-länk, installationsinstruktioner, samt en kort redogörelse för yrkescertifikat relevanta för en AI-utvecklare (till exempel AWS eller Azure).

## Vad som INTE krävs
Avancerad matematik, avancerade AI-modeller, avancerad databashantering, stora komplexa system, professionell frontend. Enkelt och begripligt slår avancerat och oförklarligt.

## Betygsgränser i korthet
- IG: saknar obligatoriska moment eller kan inte förklara koden
- G: alla obligatoriska delar finns och fungerar, kan förklaras
- VG: G plus tydlig kodstruktur, bra felhantering, djup reflektion, extra funktionalitet utöver kraven, 10+ commits

## Viktigaste enskilda risken
Att inte kunna förklara egen eller AI-genererad kod under redovisningen ger automatiskt IG. Allt som byggs i det här projektet ska vara på en nivå jag faktiskt förstår.
